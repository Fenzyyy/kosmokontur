# results/

This folder contains confirmed result artifacts from the saved Kosmokontur test material.

- `scenario_comparison.csv` — confirmed BASE vs MANDATORY STRESS KPI comparison.
- `sensitivity_matrix.xlsx` — prepared sensitivity/control matrix. Rows marked `TO RUN` are not presented as completed runs.
- `scenario_comparison.xlsx` — XLSX form of the confirmed scenario comparison.

No standalone A/B-price, ISRU-availability, or demand multiplier sweep is represented as a completed result unless the saved material contains the numeric run.
