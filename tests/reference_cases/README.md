# Reference tests from SpaceEconomyPolicy/test_oil

This directory contains machine-readable versions of the organizer's V01-V10
synthetic control cases from:

- https://github.com/SpaceEconomyPolicy/test_oil/blob/main/validation/control_cases.md
- https://github.com/SpaceEconomyPolicy/test_oil/blob/main/validation/expected_checks.json

These cases are synthetic arithmetic/semantic controls, not a competition
solution plan. The reference values are kept outside the implementation so
changes in the engine formulas cannot silently change the expected vectors.
